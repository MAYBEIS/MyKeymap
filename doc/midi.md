# MIDI 音符动作

## 简介

MyKeymap 可以把某个按键变成 **MIDI 音符**：按住时向虚拟 MIDI 端口发送 NoteOn（`0x90`），松开时发送 NoteOff（`0x80`）。这样 MyKeymap 就相当于一台 MIDI 输入设备，可以用来弹奏软音源、触发 DAW、控制灯光/视觉软件等。

- 演奏模型：**按住发声、松开停声**。
- 每个按键可独立设置「音符号 / MIDI 通道 / 力度」。

## 前置准备：建立虚拟 MIDI 端口

MyKeymap 只负责「发送」MIDI 消息，因此本机需要一个 MIDI 端口来接收并转发给目标软件。**当默认端口 `MykeyMap-Midi` 不存在时，MyKeymap 会自动在本进程内创建一个同名虚拟端口**（依赖 loopMIDI 安装的 teVirtualMIDI 驱动，安装过 loopMIDI 即具备）；也可用 loopMIDI 手动创建持久端口：

1. 安装虚拟 MIDI 端口工具（推荐 loopMIDI）。本仓库 [`tools/loopMIDI.exe`](tools/loopMIDI.exe:1) 即该工具的安装包（已被 `.gitignore` 忽略，不进版本库）。
2. 安装并启动 loopMIDI。
3. 在 loopMIDI 界面点击左下角的 **「+」** 按钮，创建一个端口。**推荐直接命名为 `MykeyMap-Midi`**，与 MyKeymap 的默认端口名保持一致，这样设置里无需再填写端口名即可直接使用；当然也可自定义名称，此时在 MyKeymap 设置里填写的端口名需与之一致。
4. 保持 loopMIDI 处于运行状态（可在其设置中勾选开机自启）。

## 配置步骤

1. 打开 MyKeymap 设置界面。
2. 在设置页的 **MIDI** 分区中填写虚拟 MIDI 端口名（例如 `MykeyMap-Midi`）。**该字段可以留空**：留空时后端会自动使用默认端口名 `MykeyMap-Midi`。若下拉为空，可直接手动输入端口名。
3. 进入按键映射界面，为某个按键选择动作类型 **🎹 MIDI 音符**。
4. 设置以下三个参数：
   - **音符号**：`C-1` 到 `G9`，共 128 个。
   - **MIDI 通道**：1–16。
   - **力度**：1–127（滑块）。
5. 保存后 MyKeymap 会重新生成脚本并生效。之后按住该键即可发声。

## 在 DAW / 软音源中接收

在目标软件中把该虚拟端口设为 MIDI **输入**：

- **DAW**（Reaper / Cubase / FL Studio 等）：在 MIDI 输入设备列表中启用 `MykeyMap-Midi`（或你自定义的端口名）。
- **独立软音源**：在音频/MIDI 设置中选择该端口作为输入。
- **灯光 / 视觉软件**：在 MIDI 输入中选择该端口，并把音符映射到对应触发。

## 音符号对照

音符号遵循 MIDI 标准，每个八度 12 个半音，`C-1 = 0`、`C4 = 60`、`G9 = 127`。

| 音名 | 音符号 | 说明 |
|---|---|---|
| C-1 | 0 | 最低音 |
| C0 | 12 | |
| C1 | 24 | |
| C2 | 36 | |
| C3 | 48 | |
| C4 | 60 | 常说的「中央 C」 |
| C5 | 72 | |
| C6 | 84 | |
| C7 | 96 | |
| C8 | 108 | |
| G9 | 127 | 最高音 |

音名使用升号制：`C C# D D# E F F# G G# A A# B`（例如 61 = `C#4`）。

## 注意事项与限制

- **仅支持键盘按键**：鼠标滚轮等没有 `up` 事件，无法可靠地发送 NoteOff，因此不适用于本动作。
- **端口来源**：优先使用本机已存在的同名端口；不存在时自动创建。自动创建的是**进程内虚拟端口**，仅在 MyKeymap 运行期间存在，退出即销毁（因此 DAW 也只在 MyKeymap 运行时能看到它）。
- **自动创建依赖 teVirtualMIDI**：安装过 loopMIDI 的机器即具备该驱动（`teVirtualMIDI64.dll`）。若本机没有该驱动，则无法自动创建，此时退回到「名字含 `loopMIDI` 的端口 > 0 号设备」。
- **端口名写错有回退行为**：匹配优先级为「精确匹配所填端口名 > 名字含 `loopMIDI` 的端口 > 0 号设备」。因此名字写错时，可能意外从其它端口发声。
- **缩写模式不适用**：该动作在缩写映射中不可选（已 `hideInAbbr`）。
- **退出/重载保护**：退出或重新加载 MyKeymap 时会自动发送 All Notes Off（CC123）并关闭端口，避免残留卡音。

## 常见问题

- **设置页下拉没有端口**：确认 loopMIDI 已运行并至少创建了一个端口；仍未出现时，直接在输入框手动填写端口名。即使下拉为空，MyKeymap 启动时也会尝试自动创建默认端口。
- **能配置但不发声**：检查目标软件是否已把该端口设为输入；确认音符号、力度不为 0；确认端口名与 loopMIDI 中的名称完全一致。
- **出现卡音**：多为退出前未收到 NoteOff。可重新触发一次同音，或重启 MyKeymap；程序已内置退出时的自动关音保护。
